# Отдельные промпты для обучения DevOps

Подготовлено 16.10.2026 по реальной практике и последним пожеланиям ученика. **16 самостоятельных промптов**. Это не новые рефераты и не новые зачёты.

## Как пользоваться

1. Открой нужный файл, скопируй его целиком и вставь первым сообщением в отдельную задачу. Общие правила уже встроены в КАЖДЫЙ промпт — отдельно склеивать ничего не нужно.
2. Для продолжения сейчас выбери **03 - Docker и Compose**: healthcheck ещё не выполнен, wget только начали разбирать.
3. Linux/сети — для углубления и точечных пробелов, а не обнуления курса. Git/Bash — отдельные дополнительные модули, потому что наличие репозитория/скрипта не доказывает самостоятельное владение.
4. Сохраняй отдельные задачи по модулям, но не запускай параллельно конфликтующие изменения одной VM. Новые преподаватели читают свежий общий checkpoint и дополняют только свой результат.
5. Сохрани эти файлы как стартовые шаблоны. Актуальный прогресс после каждого занятия живёт в CURRENT/PROGRESS и Obsidian, а не автоматически обновляется во всех 16 снимках.

## Порядок

Навигатор — необязательный обзор. Сейчас продолжаем Docker, закрывая точечные пробелы Linux/сети и Git/Bash по необходимости. Затем CI/CD → Ansible и Terraform → облачная модель → архитектура Kubernetes → эксплуатация → данные → наблюдаемость → итоговая безопасность → GitOps-проект. Безопасность и диагностика присутствуют с первого дня, не ждут финального раздела. До платного облака — отдельный выбор провайдера и бюджета.

Прежний модуль 5 разделён на 05A/05B, прежние номера остальных модулей сохранены. Не обещаем срок полного освоения в неделях: переход зависит от понимания и выполненной практики.

## Что изменено в формате

Сначала объяснение и разобранный пример, потом практика и проверка. Незнакомые команды не предлагаются как угадайка. Вместо сообщения после каждой команды — цельный блок на 20–30 минут и общий итог. Рефераты PDF/Markdown, Obsidian, шпаргалки и Git включены в каждый промпт. Работу на сервере выполняет ученик, документацию ведёт преподаватель при доступных инструментах.
