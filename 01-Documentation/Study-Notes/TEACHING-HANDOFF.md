# Передача между учебными модулями

Обновлено 16.10.2026. Это организация обучения, не новый практический зачёт.

## Новый формат

[16 самостоятельных промптов](Промпты/README.md) содержат общие правила, предметную
программу, исходный прогресс и первую тему. Роль 05 разделена на Ansible/Terraform,
добавлены отдельные Git/Bash. Промпты не меняют оценки и не увеличивают 15 рефератов.

Сначала объяснение понятий/команд и разобранный пример, затем направленная практика,
аналогичная самостоятельная задача и обратная связь. Нельзя экзаменовать по материалу,
который не объяснялся, или подменять обучение копированием большого конфига.
Блоки по 20–30 минут, один общий результат вместо ответа после каждой команды.
Документацию ведёт преподаватель; изменения на сервере выполняет ученик.

## Точная точка продолжения

Активен Docker/Compose. Linux/сеть/Bash и контейнерная практика проходились с помощью;
отдельные результаты показаны, некоторые сообщены учеником. Первый Compose-защитный
опрос закрыт; Session 09 по сети остаётся открытым. CI/CD и следующие практики
не выполнены; публикации Git преподавателем не доказывают Git-навыки ученика.

После web/proxy показаны остановка только web, curl (28) через пять секунд,
восстановление HTTP 200/v2 после start и удаление проекта down. Обещанного 502 не было.
DNS-имя web/localhost требуют закрепления. Healthcheck НЕ выполнен.

Ближайшее: объяснить wget, -q/-T/-O /dev/null, HTTP 200 против exit 0, область localhost
внутри web; разобрать простой CMD HTTP healthcheck и новые ключи. Затем ученик
проверяет config/up/ps. Старый сложный опыт с /tmp/lab-unhealthy отложен.
Задание не выдавать за выполненное. VM в ходе подготовки промптов не менялась.

## Документация и синхронизация

Активный Obsidian: iCloud → Obsidian → devops → Учёба. В каноническом имени vault
сохранён существующий пробел после devops. Файлы синхронизирует iCloud; не подключать
второй синхронизатор. Раздел промптов: Учёба/08 Промпты по модулям.

После смыслового блока — реферат Markdown/PDF по тематическому, не датированному
пути, актуальный статус, шпаргалка, Obsidian и Git. Преподаватели перечитывают свежий
checkpoint, не перетирают чужую работу и не меняют параллельно одну VM. Если доступа
к файловой системе нет, сообщают ограничение и готовят текст, не заявляют о записи.

Эти файлы — стартовый снимок. Новые результаты фиксируются отдельными checkpoint
и передачами с разграничением помощи, самостоятельности, показанного и сообщённого.
